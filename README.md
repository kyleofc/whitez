# WhiteZ Android

Hub premium de jogos Android — catálogo curado com destaques, gêneros e favoritos.

## Desenvolvimento

Requer Node.js e [Bun](https://bun.sh).

```sh
bun install
bun run dev
```

## Build

```sh
bun run build
```

## Stack

- React + TypeScript
- TanStack Start (roteamento + SSR)
- Tailwind CSS
- Firebase (Auth + Firestore)
